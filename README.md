# JNCHES vs. Inflation (and other things)

This is a Streamlit app for exploring compensation over time in the UCU member demographic. It's limited! Very limited! But interesting and helpful, I think. More documentation in the [actual web app](https://jnchesvinflation.streamlit.app/).

## Contributing

I'm pretty confident in the data extraction but not through detailed review. So that'd be good.

The About.py page details various plans and ideas for various next steps on both the pay and the USS stuff. Contact me if you want to help! The USS modelling will be a lift to say the lease.

I'm happy to enterntain random suggestions or contributions for data presentation and analyses!
